# Dünya Mutfağı · World Kitchen

Yemeklerin ülkelerini bul, mutfaktan mutfağa gez

Yemeğin hangi ülkenin mutfağından geldiğini ya da adı verilen ülkenin yemeğini seç. Bütün yemekler kökeni tartışmasız olanlardan seçildi.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Bilgi Yarışması merkez uygulamasının oyunu; ortak motor: [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru).
